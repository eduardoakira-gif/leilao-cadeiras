Leilão de cadeiras

As cadeiras que estão saindo do escritório vão para quem der o maior lance. Cada uma tem seu próprio prazo.

♥Toda a arrecadação vai para a campanha de Natal do Instituto Fluxo

Como funciona
  • Participação: entre com seu e-mail @fluxo.gg ou @w7m.com.br para dar lances. No primeiro acesso você recebe um código por e-mail; marque "Confiar neste computador" para não precisar dele de novo.
  • Lances: cada lance precisa superar o atual pelo valor mínimo indicado no card.
  • Limite por lance: para evitar erro de digitação, cada lance pode ser de no máximo 3x o valor atual.
  • Pagamento: combinado diretamente com quem arrematar. Você recebe um e-mail quando ganhar.
  • Retirada: por conta de quem arrematar. Não fazemos entrega das cadeiras.
  • Prazo: se o pagamento não for feito até a próxima data de pagamento, a cadeira volta para o leilão.
